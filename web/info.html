HOW TO PLAY

Everything you need to know about Train Tracks

What is it?

  • Train Tracks is a logic puzzle: lay one continuous railway track from the start tile to the end tile.
  • Each row and column has a number showing exactly how many track pieces it must contain.
  • The finished track must be a single connected path with no dead ends or stray pieces.

How to Solve

  1. Check how many tracks each row and column needs.
  2. Place pieces to satisfy those counts.
  3. Keep going until a single path connects start to end.

Every piece should connect to another - no dead ends.

Try it Yourself

Click a tile to cycle through its track piece.

Solving Algorithms

Head to the Solve screen to compare two approaches side by side: Depth First Search (with three optional neighbour-ordering heuristics) and Breadth First Search. Each one shows its search process directly on the grid as it runs, with a live step counter.
